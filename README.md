# 意客AI

面向各行业企业的 AI 商机工作台：理解企业业务，从多平台真实需求发现、证据判断，走到确认后触达、回复与跟进。

**产品代码统一提交到 `yike-ai2026/main`。** 小范围串行改动直接在 `main` 验证、审核与提交；较大或并行开发才使用短期 `codex/<主题>` 分支，完成后合并清理。`yike-ai` 暂时为只读权威文档仓库；后续迁移安排见[仓库工作流](docs/REPOSITORY_WORKFLOW.md)。

当前开发目标是 **V0.2 跨行业完整获客版**。用户已明确首发面向所有行业企业；展台仅是历史样例，不限制首发客群。业务理解与行业策略、证据化商机、持续变化提醒和完整行动闭环均纳入首发，量化验收见[产品计划](docs/V02_COMMERCIAL_RELEASE_PLAN.md)。现有代码具备客户试用的画像、研究包导入、机会证据与人工跟进基础；新增行业策略、平台连接、采集、持续监控、真实收发及 Windows 交付尚待完成，不将本说明视为已支持清单或全行业效果证明。

2026-09-10 用户再次确认按原 V0.2 **全量推进**，此前将完整版本停放的精简安排已被取代。工程 V0.2 与对外 V1.0 是同一首发规划；按可验收批次推进全部 V02-01～10，当前决定见[范围说明](docs/V02_COMMERCIAL_RELEASE_PLAN.md#10-当前执行完整-v02-全量推进2026-09-10)，开发状态只看[实施任务书](docs/V02_IMPLEMENTATION_TASKBOOK.md)。
