## 分期与实现边界

V1.0/V1.1 是用户讨论的首个正式商用版与后续增强版分期，**不修改仓库 V0.2、应用 0.2.0 或既有台账编号**。首版基础仍包括多平台采集、持续监控、真实触达、回复跟进、安全恢复和安装交付；它们不能因 R4 亮点设计而被替换。

- **V1.0 目标**：可解释的需求分类与观察视图、四类搜索结果、分用途短句建议、固定顺序补证与可执行研究上限、人工确认的“多找类似”、有证据的同项目时间线、桌面简报。
- **V1.1 边界**：依据本客户真实样本做文案效果/实验、来源效率与补证路径优化、主动扩展及预算分配、可靠标识支撑的跨帖/跨平台事件关联，以及微信/企微通知与移动端。不能提前显示提升率、自动归因或已接通渠道。

当前正在实现 R4 页面交互与服务合同，复用前端草稿保护、任务/发送原请求核对、来源事实、人工跟进和待办队列。真实研究、执行、计量和触达服务须分别验收；隔离 TEST 数据和设计示例不证明真实账号、付费用量或业务业绩。实施进度统一见[任务书](../../docs/V02_IMPLEMENTATION_TASKBOOK.md)。
