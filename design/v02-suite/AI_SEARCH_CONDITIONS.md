# AI 搜索条件建议 · R2

日期：2026-09-09。范围：P06 新建获客任务、P20 持续监控设置、P19 启动确认。状态：设计及功能要求已更新，界面与建议服务尚未实现，整套设计仍待用户确认。

## 用户获得的结果

选择已确认的业务画像后，自动得到一批可修改的搜索关键词和排除词，快速调整后进入平台连接与启动确认。AI 负责准备搜索方案，用户决定实际采用什么。

建议优先覆盖买家会说的话、采购动作与业务同义表达。比如示例画像“展台设计搭建”，可产生“找展台搭建”“展位施工询价”“展台搭建报价”等；不能只堆行业名称，也不能把推荐关键词说成已发现客户。

## 生成与编辑流程

1. 从已确认画像进入新任务时带入该画像；只有一个有效画像时可预选。存在多个画像时明确当前选择；没有已确认画像时提供选择/完善入口，保留手动填写能力，不凭空声称“已根据你的业务生成”。
2. 首次确定画像且字段未被人工编辑时，自动请求建议；关键词区就地显示“正在根据业务画像准备搜索条件”，不弹出聊天窗口。进入已保存草稿或模板时优先加载已有配置，不反复自动生成。
3. 首次有效返回填入草稿，显示“AI 建议”和依据画像；建议 8–12 个不同意图的关键词，实际数量按业务信息和平台约束确定，不为凑数重复。排除词单独展示，允许全部删除；缺少依据时可以不给排除词。
4. 用户可逐词编辑、删除、新增，也可直接粘贴多词。人工编辑立即成为当前草稿，下一步与保存都使用这份草稿。建议不会自动启动搜索、扩大平台范围或提高监控频率。
5. “重新生成”先展示一批候选建议，不覆盖当前内容。用户选择“追加新词”“替换未修改的建议词”或取消；人工新增/修改的词始终保留。清空全部或替换人工内容需另有明确操作，不由重新生成隐式执行。追加时去重，用户删除过的建议不自动补回。
6. 切换画像后提示旧条件来自哪个画像，保留人工内容；新建议仍按上述方式应用。未解决的画像版本变化在启动摘要明确提示，用户确认使用的画像与最终条件后才能启动。
7. P20 复用同一条件编辑器和生成行为；切换单次/持续监控保留搜索草稿，重新生成搜索词不改变已填时间、频率、时区和设备。
8. P19 只呈现当前最终条件、画像版本、平台/账号、设备及运行设置；返回修改去 P06/P20。确认页不重新生成，也不自行把当前草稿换回初始建议。

## 信息来源与范围

- 输入限当前客户已确认的画像版本：服务、客群、地区、交付范围、明确排除项；经用户选择的业务资料可以补充行业表达，不能把内部客户名称、联系方式或私密案例内容直接拼入平台搜索词。
- 需求表达可由模型提出，但预算、联系人、采购项目、支持的平台能力等事实不能被编造。缺少业务范围时标记待补充，不把猜测记为已确认画像。
- 按已选择且实际支持的来源生成适合该平台的表达；来源建议是可选项，用户应用后才变更平台选择，不能因模型推荐而自动连接或新增执行平台。
- 地区优先使用平台支持的范围过滤或少量有依据的组合，避免每个词机械加地名漏掉需求。排除项需检查与搜索词/画像的冲突，不用过宽的“设计”“搭建”“推荐”等词误杀需求。
- 界面不展示内部采集引擎、Skill、提示词或模型参数。客户看到的是业务画像、搜索条件、建议来源和可编辑结果。

## 必须定义的状态

| 状态 | 行为 |
|---|---|
| 未选择/未确认画像 | 可保存手工草稿；提示选择/完善画像；不伪造个性化建议 |
| 首次生成中 | 保留其他表单输入；用户可取消或转手动编辑；开始手动编辑后晚到的结果只进入待应用建议 |
| 生成成功 | 填充尚未编辑的初始字段，去重；显示画像依据及可编辑标签 |
| 超时/失败/服务不可用 | 保留全部内容，支持重试与手动填写；人工配置可进入后续步骤，不用模板冒充 AI 成功 |
| 请求返回时画像/草稿已变化 | 丢弃过期响应或作为明确的待应用建议；不得覆盖新画像的草稿 |
| 重新生成有人工修改 | 并排/分组预览当前与新增词，应用方式明确，默认保留人工修改 |
| 关键词与排除词冲突 | 标出冲突词与影响，允许删除或修改；阻止静默把全部有效搜索排除 |
| 平台不支持某种搜索语法 | 使用该平台有效表达或提示用户调整；不把不支持的布尔语法直接执行 |
| 启动前条件发生变化 | 摘要重新读取当前已保存版本，旧确认失效；以最终确认的配置执行 |

## 实施归属与验收

V02-04 增加搜索建议能力的输入/输出校验与真实模型调用；V02-05 接入自动触发、可编辑条件、生成状态与人工修改保护。沿用版本化研究方法的业务理解和证据边界，但需新增任务搜索建议的专用输出，现有研究规则包本身不代表这项能力已实现。

每次建议记录客户身份、画像版本、请求 ID、规则/模型版本及生成结果；草稿另保留当前词项、建议来源、人工新增/修改/删除记录和当前版本。租户由服务端身份解析；同一草稿/画像的过期请求不能回写。按当前任务预算限制生成与重试，避免每次重绘/返回页面都重新收费调用。

验收应实际覆盖：两个不同画像得到不同且相关的建议；首次选择后无需手写种子词即可得到结果；用户修改后重新生成不丢修改；删除词不会自动复活；切画像和并发响应不串写；失败可继续手填；P06/P20/P19 保持同一最终条件；零真实线索时不宣称推荐有效。

产品验证看首次任务配置耗时、建议采纳/修改情况及后续去重有效线索比例；不以“生成了多少词”或 AI 动画证明效果。当前不承诺提高多少转化，也没有伪造模型调用或付费数据。
