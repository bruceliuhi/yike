# CP-01 / CP-02 架构门禁记录

审查对象：`codex/customer-pilot` 独立工作区。审查人为未参与实现的独立架构 Agent，结论为只读审查意见，不是代码通过证明。

## 初始结论

旧实现仍是单租户 SQLite 双平台发现 MVP，CP-01/CP-02 不得直接开始。主要阻断项：缺少 PostgreSQL 驱动与迁移；业务表没有 `tenant_id`；没有版本化业务画像；运行时与旧 MVP 共用命名空间；没有历史数据迁移策略；没有真实 PostgreSQL、跨租户拒绝和画像版本追溯测试。

## 本分支修复边界

本分支采用独立 `pilot/` 包和 `migrations/101_customer_pilot.sql`，生产连接必须显式提供 PostgreSQL URL；客户数据按 tenant 作用域；画像版本追加保存；机会导入使用租户内幂等键；旧 SQLite 数据默认不迁移。旧 `app/`、旧迁移和旧采集器不作为 pilot 运行时依赖。

## 放行条件

只有在真实 PostgreSQL 空库迁移、两租户读写隔离、画像版本追溯、重复导入幂等和旧库不被读取的测试均通过后，CP-01 才可标记完成；本文件不替代后续独立代码审核和质量验收。
