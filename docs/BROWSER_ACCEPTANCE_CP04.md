# CP-04 浏览器主流程验收记录

时间：2026-09-08 22:58（Asia/Shanghai）

环境：独立临时 PostgreSQL 15 容器、本机 Uvicorn `127.0.0.1:8787`、显式 `YIKE_PILOT_DEV_LOGIN=1`。验收数据是一条人工复核研究包导入的展台设计机会；未向任何外部平台发送消息。

## 实际操作

1. 浏览器打开 `/profile`，填写展台设计搭建服务描述。
2. 提交后显示“画像版本 2 已保存”，确认画像版本。
3. 自动进入 `/opportunities`，看到“寻找展台设计搭建团队”。
4. 打开详情页，看到买方、需求摘要、平台、发布时间、公开摘录、可重开原文链接、独立公开评论草稿和私信草稿，并显示“仅供人工复制，不自动发送”。
5. 在详情页确认来源状态下拉框可选择 OPEN/EXPIRED/BLOCKED/UNVERIFIED。
6. 提交跟进备注“浏览器验收：已核对原始证据，未向外部平台发送”。页面返回详情页。
7. 打开独立 `/followups` 页面，看到该条 CONTACTED 记录及备注。

## 数据核对

数据库查询确认最新跟进记录为：`CONTACTED`，备注与页面提交一致；独立跟进页显示同一记录。服务器日志只出现本机 HTTP 路由，没有外部平台请求。

## 边界

这是本机浏览器主流程证据，不是公网部署、HTTPS、真实手机或真实客户试用证明；开发登录桥接仅供本机显式开启，生产必须关闭。
