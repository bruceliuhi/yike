# 意客 AI 客户试用实现计划

## 阶段与停止条件

### CP-01 权威与基础设施 — 实现增量完成，部署门禁未完成

- 确认本分支独立于既有双平台发现 MVP。
- 增加 PostgreSQL 配置、迁移和健康检查。
- 保留 SQLite 仅用于本地离线测试，并显式标记运行模式。

验收：空 PostgreSQL 数据库可迁移；缺少数据库配置时明确失败；不会静默切到共享生产库。当前证据见 `docs/CP01_EVIDENCE.md`；生产 ACL/HTTPS 尚未验收。

### CP-02 画像与租户边界 — 本地客户路径增量完成，强隔离部署未完成

- 业务画像版本、确认状态和服务地域持久化。
- 所有客户查询由服务端身份解析 tenant_id。
- 画像更新不覆盖历史版本，新的搜索任务只引用已确认版本。

验收：两个测试租户互不可读写；旧版本可追溯；Web 只接受签名用户令牌，客户端不能传 `tenant_id`。数据库直连隔离仍依赖私网 ACL/角色配置，必须在目标环境复核。

### CP-03 机会证据与重复控制 — 研究包门禁、来源版本/观察、任务租约已实现，机会聚类待做

- 导入来源、内容版本、观察记录和机会关联。
- 研究包必须标记人工复核通过，并包含可重开链接、UTC 原帖时间、联系路径和独立评论/私信草稿。
- 任务幂等键、数据库唯一约束和过期租约；已提供原子领取、完成、失败和过期接管方法。
- 同项目聚类先标记疑似关联，保留拆分入口。

验收：重复导入不增加机会；重跑增加 observation；内容变化产生版本；并发旧任务不能回写新状态。研究包命令行导入入口已提供，仍需在目标部署环境复核权限与审计留痕。

### CP-04 四页用户路径 — 最小浏览器闭环已验收，结果状态已扩展

- 业务画像、机会列表、详情/草稿、跟进反馈四页；跟进支持联系、回复、会议、报价、失单和成交状态。
- 空结果、过期来源、来源受阻和导入失败提供明确状态。
- 联系草稿只供编辑和复制，发送由用户在平台完成后登记。

验收：空库启动、真实研究包导入、查看证据、记录反馈走通；不展示模拟成交。

### CP-05 独立质量门禁

- 独立代码审核 Agent 绑定每个实现提交。
- 独立质量 Agent 运行自动测试、空库浏览器流程和敏感信息扫描。
- 修复后复审并保留报告。

验收：所有阻断项关闭；提交、测试、审核报告和运行说明可追溯。

### CP-06 受控部署与试用

- 在明确的目标环境部署，使用 `/healthz` 与 `/readyz` 验证进程/数据库就绪，并验证 HTTPS、日志脱敏、备份恢复和回滚。
- 应用镜像骨架见 `deploy/Dockerfile`；镜像构建不等于目标环境上线，仍需记录部署 SHA 和运行探针结果。
- 备份/恢复脚本见 `scripts/backup_pilot.sh` 与 `scripts/restore_pilot.sh`；脚本存在不等于已完成目标库恢复演练。
- 使用真实手机完成四页流程。
- 只在部署证据完整后准备基于真实界面的推广素材。

验收：提供部署地址、部署 SHA、环境检查、手机验收记录和剩余限制；不将 HTTP 200 单独视为上线。
