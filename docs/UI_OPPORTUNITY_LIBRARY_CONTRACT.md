# P10 商机库结构化来源事实契约

日期：2026-09-09。适用：R3 P10 独立的“阶段 / 状态 / 资料截止”三列。当前默认 pilot 接口尚不提供阶段和截止事实；本文件定义向后兼容的可选响应，不能据此宣称后端已实现。

## 当前接口与新增边界

现有 `GET /api/ui/opportunities` 和 `GET /api/ui/opportunities/{id}` 沿用认证、租户隔离、固定 IPC operation。既有 `intent_status` 是商机处理状态，`latest_followup_status` 是跟进记录，`source_status` 是来源状态；三者都不能作为采购/需求阶段。`published_at`、`updated_at` 也不能当资料截止。前端不解析标题、`action_signal` 或摘录来自动填字段。

仅向现有单条商机响应追加以下可选字段，不增加任意查询路径、header、管理员凭据或写操作：

```json
{
  "opportunity_id": "TEST-opportunity",
  "public_url": "https://example.test/TEST-source",
  "source_observed_at": "2026-09-09T09:00:00+08:00",
  "source_evidence_version": "TEST-evidence-v3",
  "library_facts": {
    "schema_version": 1,
    "opportunity_id": "TEST-opportunity",
    "source_url": "https://example.test/TEST-source",
    "observed_at": "2026-09-09T09:00:00+08:00",
    "evidence_version": "TEST-evidence-v3",
    "stage": {"status": "KNOWN", "label": "预算询价", "evidence_excerpt": "TEST 本次属于预算编制阶段询价。"},
    "materials_deadline": {"status": "KNOWN", "at": "2026-09-15T18:00:00+08:00", "evidence_excerpt": "TEST 资料截止为9月15日18:00（北京时间）。"}
  }
}
```

上例为 TEST，不是客户数据。`stage.label` 是服务端由来源证据明确提供的业务阶段（1–80 字符），允许各行业采用自己的真实名称，不硬编码全行业采购阶段枚举。状态仅允许 `KNOWN` 或 `UNKNOWN`，后者不带事实值；未知状态不映射为任何已知阶段。资料截止允许 `KNOWN`（带时区时间与摘录）、`NOT_STATED`（来源未说明，带核对摘录）或 `UNKNOWN`（待核验）。`KNOWN` 不代表商机已经人工入库复核、具备发送条件、供应商已中标或已成交。

事实绑定当前机会 ID、来源 URL、来源观察时间和证据版本。来源 URL 必须为无用户名/密码的 HTTP(S) URL，且与 `public_url` 完全一致；时间按同一瞬间比较；证据版本非空、最长 128 字符且必须匹配当前 `source_evidence_version`。后端应在同一读取快照给出当前来源锚点，证据更新时不可沿用旧 facts 配新锚点。由来源查询与审核服务决定是否可以提供事实，前端不会创建或推进来源观察版本。

`at` 和观察时间要求显式 RFC3339 时区（Z 或 offset）、真实日历日期和有效时分秒。缺时区、仅日期、2月30日、24:00、未知时区 -00:00 等不可用。若来源只有日期而没有时间，必须 `UNKNOWN`；不得擅自补午夜或23:59。

## 界面与失败状态

| 数据情况 | 阶段 / 资料截止表现 |
| --- | --- |
| `library_facts` 缺失或 null | 尚未提供，保留其它真实商机字段和操作 |
| 事实格式非法、schema/state 未知、ID/URL/观察版本失配、缺当前锚点 | 待核验；提示原因是事实格式或来源观察版本不一致 |
| 有效事实中的 `UNKNOWN` | 待核验 |
| 截止 `NOT_STATED` | 来源未说明；不能视为永不过期 |
| 截止 `KNOWN` | 显示原来源时区时间；保留年份、时区及证据提示 |
| 客户列表权限、网络或超时失败 | 明确错误和重试，不显示成“暂无客户商机” |

客户端在约 30 秒内结束挂起读取，旧读取结果受资源代次和登录身份限制。当前列表 API 为完整快照，筛选/分页/排序只在已读取快照内完成；将来改成服务端分页时必须另升级查询/总数契约，不能把当前页当全集。

阶段可按真实 label、尚未提供、待核验筛选。截止可按未截止、7天内、已截止、来源未说明、尚未提供、待核验筛选；全部控件可操作，无匹配时提供重置。7天指当前瞬间后的 168 小时，截止瞬间及之后属于已截止；来源未说明和未知值不混入有效期限结果。界面每30秒刷新时间筛选，实际操作资格始终由各业务服务重核，不由显示值授权。资料截止升序将未知值放在最后。详情返回保留筛选、排序和页码；切换样例/客户范围清除阶段和截止条件。

CSV 与表格使用相同的已校验字段，并显示完整年份/时区。沿用公式转义、仅选中客户、排除公开样例和实际保存回执，截止列不替代原生导出确认。

## 公开样例与验收

公开样例仅以[湖南省商务厅公告](https://swt.hunan.gov.cn/swt/hnswt/85753/fdzdgknr/caizhengxinxi/zfcgh/202609/t20260908_44997689265690696.html)为依据：本轮重新读取的官方原文明确预算编制阶段询价，资料截止为2026-09-15 18:00（北京时间）。其来源观察记录是本次静态样例核对，不代表后台产生了观察任务；样例继续未入客户库、不可选择/导出，不自动将这些字段带给客户机会。测试仅使用 TEST 合成数据，`tests/visual/fixtures.ts` 的展示事实也有 TEST 标记，不被生产导入。

针对性验收覆盖字段缺失、非法schema/状态、URL/ID/观察时间/版本失配、午夜及非法日期、跨时区比较、真实阶段组合筛选、最早截止排序、筛选返回、无结果、来源Logo、CSV转义与样例隔离、权限/挂起重试、旧响应与身份切换。生产后端字段、真实数据质量、浏览器视觉及原生客户端分别验收，不由隔离组件测试代替。
