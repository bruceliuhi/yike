确认后的搜索建议保护人工修改和删除；过期响应不能覆盖新画像或编辑。既有访问凭证、画像、商机和跟进通过 `/api/ui` 真实连接，未接能力返回明确失败，默认运行路径没有测试替身。公开研究样例不能入客户库或发送。复制、人工登记、渠道发送回执、实际回复分别处理。

草稿按用户隔离，保存在本机当前会话。发送/任务未知结果使用独立操作记录，只持久化用户范围内的 ID 和状态；清草稿或退出不清除此记录。其作用是防止本机盲目重试，不能替代服务端幂等、授权和回执对账；这些是实际发送/执行接入的前置契约。

## Windows 后续操作

在 Windows PowerShell、Node.js 24 x64 环境，使用一个新的目录：

```powershell
git clone --branch codex/ui-r3-desktop --single-branch https://gitee.com/xinghetech/yike-ai2026.git yike-ai-ui-r3
cd yike-ai-ui-r3/desktop
./scripts/build-windows.ps1
```
