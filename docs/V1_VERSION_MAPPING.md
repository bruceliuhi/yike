日期：2026-09-09。

本文把既有 `V02-*` 工程任务映射为对外版本，不大规模重命名任务、模块或迁移。`V02-*` 仍是工程分解与验收编号；V1.0 是首个正式商用版，V1.1 是上线后的数据驱动增强版。当前只授权 V1.0 实施；V1.1 保留设计但未启动，不预先构建学习系统。实际认领、状态、SHA、ACK 和证据只记在 [实施任务书](V02_IMPLEMENTATION_TASKBOOK.md)。

## 不变的商用门槛

V1.0 继承当前全行业、多平台采集与监控、原文证据判断、人工确认后真实发送、回复关联与跟进、Windows 交付、安全隔离与恢复全部范围。发布仍需 M3、CP-06、独立审核及五类业务各两家企业连续 14 天验证。版本映射不授权对外发送、支付、部署或绕过验证码、限流和平台风控。

## 增量顺序

按用户同日追加要求，先交付“内部纵向贯通 → 邀请试用 → 正式商用”的可用闭环，详见[产品计划第1.1～1.2节](V02_COMMERCIAL_RELEASE_PLAN.md)。证据卡、搜索范围解释、多找类似的固定策略版本和建联短句/回复闭环在邀请试用阶段即可体验，不等复杂管理、统计或自动更新完成；实际功能仍按原依赖逐项接通。邀请试用不是删减后的 V1.0 正式版。

V1.1 顺序为：**来源效果积累 → 自动扩展/预算优化 → 跨源关联 → 微信/企微简报**。不提前构建自动学习平台；高级自动化不是上述首轮亮点的前置依赖。

同日分工更新：04A/B资料/画像/策略服务及05B/C由Win纵向交付，Mac接收、负责执行与候选/复核/收发；下表“建议主责”中涉及04A/B的策略部分以任务书第7节实际接收为准，不新建状态表。

## V1.0 搜索透明度

属性：V1.0 增强。工程映射为 03A/03B 服务端运行覆盖、错误和预算证据，02B 来源/run 实际事实，04B/04C 策略和排除理由，05E 客户端呈现，需要任务运输时由05F接入。Mac 负责权威分类与证据，Win 负责呈现。依赖逐平台真实 run/搜索审计、04B 已确认策略版本和预算，以及02B入库记录；这些尚未齐备时不得将计划当成已实现。

- 分开访问失败、预算耗尽/未覆盖、重复/过期/不匹配排除、已检查范围无合格机会。
- 显示实际平台、搜索方向、独立来源和排除原因；搜索失败不写成“无新商机”，不声称穷尽全网。
- 未接通/未验收来源不进入“已搜索平台”。

V1.0 预留来源/查询/画像和规则版本/成本/反馈溯源字段，但不表示 V1.1 自动扩展、动态预算或跨源合并已启动。
