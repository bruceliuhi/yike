# 运营后台与三天试用访问码

授权：用户要求管理员看完整手机号、试用码默认三天，并提交 main。

## 最小交付

- 独立 `/ops` 运营应用，独立管理员认证与受限数据库角色；普通客户端无运营权限。
- 管理员通过微信等外部渠道发放高熵试用访问码。手机号必须先通过真实短信验证码验证；访问码只负责开通权益，不替代身份验证。默认从首次成功激活起 72 小时；可设置 1–30 天；一次激活并绑定用户，可停用。
- 完整手机号仅授权后台展示，数据库加密保存；客户端不返回手机号，日志不记录手机号或凭证。历史 hash 无法还原，不伪造旧用户手机号。
- 首次开通使用手机号＋真实短信验证码＋运营发放的试用码；后续使用手机号＋短信验证码登录，不重复要求试用码。短信验证和权益激活必须保持一致性，失败不能产生已开通权限。
- 到期或停用后，旧会话也失效。访问码只展示一次，仅保存摘要。按手机号码唯一，避免重复创建试用租户。
- 不做付费、批量导出、销售 CRM；本任务不包含生产部署及密钥创建。现有短信能力只有依赖注入协议与测试替身，正式运行时未接入供应商，需要确认用户短信渠道、签名、模板的配置位置后接入；无供应商配置时明确不可用，不能退化成试用码直接登录。
