## 实现

- 前端实际调用已有认证 `GET /api/ui/connections`：浏览器同源凭据，桌面固定 `connections.list` IPC 白名单，调用者不能指定任意 URL、租户或认证头。
- 显式解码服务端登记模型，保留连接、设备、账号、版本与时间。同一平台多个账号、同一账号多个设备分别显示，旧平台检查不会覆盖其它登记记录。
- `UNVERIFIED` 显示待核验；`CONNECTED` 保留为登记状态，能力仍未知，不能据此启用采集/发送。旧平台级断开不能操作带设备/版本的登记记录。
- 详情支持刷新；加载时隐藏旧记录，失败与真实空列表区分，切换账户空间关闭详情并丢弃旧请求结果。设备标签保留可区分信息，长账号允许换行。
