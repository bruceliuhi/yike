# R3 设计与运行页面检查

设计基准：`5929de6` 的 [P01–P20](../../../design/v02-suite-r3/README.md)、DESIGN_SYSTEM 与后续平台官方Logo要求。UI代码 `58c8a7d`，整合 `b89df6c` 的renderer相同。结果是本批可见页面与所列交互检查通过，完整状态矩阵尚未验完。

## 捕获方法

最终20张 `screens/P01.png` 至 `P20.png` 来自CUA控制的独立Chrome页面：1484×1060 CSS px、DPR1、PNG原图。对应 `-raw.png` 与标准图同字节，没有重采样、拼接或像素编辑。尺寸、路由及额外点击状态在 [captures.json](screens/captures.json)。

内置浏览器初次大图捕获出现模糊/重复片块，该批没有作为最终视觉通过证据；诊断原图保留在本机 `desktop/out/qa-iab-rejected/`，不进入交付图册。浏览器测试夹具有显式 TEST 标记，不能当作客户运行数据。每页由reference与implementation同时输入人工判断，不是只检查文件存在。

## 适配范围

[responsive.json](screens/responsive.json)：20页分别在1280×720、1366×768、1440×1024、1920×1080、2560×1440和960×600实际CSS视口下检查，共120项无文档横向溢出。逐次记录实际innerWidth/innerHeight而非只相信请求尺寸。该检查不代表所有长表格或弹窗每个状态都完成像素审核，也不替代Windows系统缩放。

## 剩余状态验收

以下仍需逐条对照 [PAGE_STATE_MATRIX](../../../design/v02-suite-r3/PAGE_STATE_MATRIX.md)，沿用既有代码与测试，不重复开发已经实现的状态：

- P01–P05：验证码倒计时/服务错误、待办缺目标、画像离开保护、资料撤销/未知状态、采集取消结果。
- P06–P11：AI等待期间编辑/删除的可见候选应用、真实候选批量复核、监控暂停/恢复及执行事件、来源阻断/版本历史、导出失败提示。
- P12–P18：触达各队列与重生成编辑保护、未匹配回复/已读、跟进保存失败、真实平台断开恢复、设备/恢复/更新的全部异常组合。
- P19–P20：真实执行服务的查询回执、监控跨日/时区/DST组合以及全页离线/权限/会话过期交叉状态。

已存在回归测试不等于本批逐个可见走查；真实业务后台与平台能力没有因这些TEST演练变为已接通。
