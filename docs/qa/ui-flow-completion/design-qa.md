## 方法

参考为 `design/v02-suite-r3/screens/P01.png` 至 `P20.png`。使用真实 React 页面、隔离 TEST 内存数据，在 CSS **1484×1060** 下截图；浏览器原始图为 1855×1325（用户浏览器缩放 125%），按同一比例归一化。P05/P07/P20 原设计图存在约 1px 尺寸差。每对参考和运行图均放在同一次图像工具输入中实际观察，未用截图文件存在代替判断。

布局尺寸和字号按 DESIGN_SYSTEM，而非生成图片中偏大的字形测量。顶部 TEST 标签只属于隔离测试入口；正常产品没有 TEST 假客户。`reference=r3` 对齐草稿、未连接、空队列和公开样例等状态；`capabilities=complete` 仅用于验证可选服务存在时的前端交互，两者均不证明真实后台已接通。

主任务核对 P04/P06/P08/P19/P20，并再次复看 P01/P02/P05/P11/P12/P13/P15；Agent B 独立打开其余页面的 15 对图，范围与差异见 [质量复核](QUALITY_REVIEW.md)。P05/P08 模板和配置展开、P15 滚动、P19 行高修复以后，本记录的后续证据优先于初轮观察。

## 实际交互与适配

- 资料 TEST 完整链：新增正文 → 同步草稿v1 → 解析为待核对v2 → 人工勾选确认v3 → 选择字段填入画像草稿 → 离开提示 → 切到业务描述后文本仍保留 → 保存为新画像草稿。确认资料没有自动确认业务画像。证据：[已确认](screens/materials-confirmed.png)、[填入草稿](screens/materials-applied.png)。所有操作仅在测试内存发生。
- 跟进 TEST 完整链：选择事实类型/备注/下一步 → 保存 → 全部记录中定位新增 → 关联回复标为已读 → 人工登记 → 纠正备注并填写原因 → 保存后原记录标已纠正且继续可读。证据：[纠正记录](screens/followup-corrected.png)。未发出真实联系或写入客户库。
- [六尺寸测量](screens/responsive.json)：P04/P12/P15/P19/P20 × 1280×720、1366×768、1440×1024、1920×1080、2560×1440、960×600，共30项；无文档横向溢出。长表单允许纵向滚动。此批 P19 尺寸早于最终行高收敛，最终标准视口按上表记录。
- P15 在1484×1060下 body高858、内容高916，实际滚动至57.6后，说明全文与固定底栏均完整。证据：[标准视口滚动](screens/P15-scrolled.png)、[960×600滚动](screens/P15-960x600-scrolled.png)、[测量](screens/P15-scroll.json)。小窗口长表单滚动后仍能操作负责人和保存。
- 错误、超时、取消、原请求查询、跨身份/版本迟到、重复操作、样例保护等由组件/契约测试覆盖。不能将自动化状态测试表述成每个错误状态都与设计逐图比对完成。

正常视口实际产品 [连接页](screens/brand/product-connections.png) 已确认四图可读；测试图中四个品牌图像均已完成加载（naturalWidth>0），平台状态仍独立显示，不用 Logo 冒充连接成功。品牌后的小窗口 [尺寸记录](screens/brand/responsive.json) 为 P06/P08/P16/P19 × 1280×720、960×600，无文档横向溢出；长内容需纵向滚动。
