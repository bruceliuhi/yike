## 证据如何计入

- **已实现**：源码具备对应分支；默认服务未接通时可以准确显示不可用。不能等同于真实后台完成。
- **已验证**：仅计入报告明确记载的版本、场景和环境。例如，组件测试证明状态转换，浏览器走查证明所列动作及可见反馈。
- **弱证据 / 缺证据**：只有页面截图、无横向溢出检查或组件回归，尚不足以证明全部弹窗、失败恢复、键盘和滚动状态可用。这里不把“未验”写成“已坏”。
- **外部依赖**：真实平台、模型/计量/消息、Windows 实机等需相应环境；不为结束 UI Goal 而伪造这些能力。
