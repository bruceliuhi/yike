日期：2026-09-09。基线 `15ddb70`；最终代码候选 `a9f3078b98ffe443ee5b7d95b7bc5ff55530a2e5`（`8011a30` 加入口/版式修复）；macOS 构建见本目录 `mac-package.json`。本轮只向 `yike-ai2026/main` 交付，`yike-ai` 未修改。

## 实际变化

- P01：登录交换、身份刷新和首屏会话读取有等待上限；过期响应不能重新写入旧身份。
- P06/P20：AI 条件建议支持取消、45 秒超时；已保存空草稿不会反复生成，切换画像保留条件来源提示。
- P17：连接和检查 30 秒超时，关闭/切换后的结果隔离。取消 UI 等待不表示平台原生操作已撤销。
- P10：通过原生保存对话框导出 CSV；原子写入完成才报告保存，取消不会显示成功。浏览器只报告下载发起。
- P12/P13：三队列状态、首次生成与保留编辑、原 requestId 核对、确认版本与最新防重锁。旧 FAILED 不冒充确定未送达。
- P18：账号/设备状态，绑定与解绑影响预览、客户数据导出、备份文件检查及恢复预览、更新/取消/回退界面，30 秒未知操作保护。设置行与弹窗间距收紧。

`ManagementService` 与 `OutreachService` 是可选接入契约。默认运行没有真实管理/队列/发送后端；对应可用状态通过隔离测试验证，不能描述为平台已连接、已发消息或真实恢复了客户库。原生文件保存链路是本轮实际桌面能力；保存对话框的自动化替代和可见客户端验证分开记录。

## 证据与限制

- 自动测试及命令：`checks.json`；架构、代码、质量及原生导出独立审核在同目录。审核排除各自实现模块。
- macOS：本轮最终包 SHA 与 ASAR、资源/网络/文件回执检查见 `mac-package.json`；可见操作见 `mac-visible.json`。
- 浏览器：`responsive.json` 检查 P12/P18 的 1280×720、1366×768、1440×1024、1920×1080、2560×1440、960×600，共 12 个无横向溢出结果。此项不等于 Windows 系统缩放验收。
- P18 最小窗口弹窗：`dialog-960.json` 与 `screens/P18-backup-960.png`，底部按钮在可见范围内。
- 视觉对照见 [VISUAL_REVIEW.md](VISUAL_REVIEW.md)。P12/P18 与图册同为 1484×1060 CSS 视口检查；本轮不宣称 20 页达到逐像素一致。
