- 检查结束已撤销浏览器测试尺寸覆盖，开发工作台保持可见。

## 实际 PostgreSQL 与浏览器

本机临时 PostgreSQL 16，固定镜像摘要 `sha256:f1c3376c26f2609ab9f29f71f824103fe2fcd8ee0346485cb6122a4f93df6f94`，独立临时库和测试租户；应用使用 NOSUPERUSER / NOBYPASSRLS 角色，与迁移管理员连接分开。22项结果见 [API/数据库记录](postgres-api-check.json)。

通过与 API 同 origin 的生产前端资源 `/app/`，实际操作访问凭证登录、填写并保存画像、确认 v1、新建任务自动绑定该已确认画像、退出并返回登录页。仅使用标明“非业务客户”的隔离测试记录，未采集或发送；[真实画像确认截图](screens/real-postgres-profile.png)。临时凭证和数据库口令不进入仓库。

## 最终 Mac 应用可见验收

使用最终 [Mac 包](mac-package.json)，通过 CUA 启动 `意客AI.app`，窗口资源来自 `yike://app/index.html`，不依赖 Vite 开发服务器。

1. 工作台、Y Logo、八个业务入口正常渲染。
2. 创建“Mac 客户端验收草稿”，批量加入“展台设计,展会搭建”，选小红书，保存出现本机会话成功提示。
3. 前进至平台连接与最终确认；任务名、关键词、平台原样保留；未配置服务/画像/设备时列出阻断，不能启动。
4. 用 Cmd+Q 退出，确认包内主进程已退出；重新打开后工作台正常渲染。
5. 证据：[客户端工作台](screens/mac-workbench.png)、[确认页](screens/mac-confirmation.png)。

此次没有真实 HTTPS 服务、平台登录/执行器或客户账号，不扩大声称这些功能通过；Windows 构建、安装、卸载和100%/125%/150%系统缩放由用户后续手动执行。
