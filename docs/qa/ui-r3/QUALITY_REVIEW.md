## 功能与状态边界

- API 身份来自已验证会话并由服务端解析租户；输入禁止额外租户 / 用户字段，客户数据路由要求认证。画像与跟进沿用现有真实存储；错误不回显凭证和内部数据库信息。既有 Origin 中间件和 HTTPS 会话要求仍保留。
- 实际服务适配只接入现有会话、画像、商机、人工跟进能力。平台连接、采集执行、AI 建议、消息发送和回复等未接通能力明确失败，没有默认假成功返回。
- Profile 的失败保留输入、确认版本复核，Connections 的过期异步结果丢弃与平台匹配，Settings 的退出复核与脱敏诊断均有实现及针对性测试。资料仍明确保存在本机会话中，没有冒称已上传后台。
- TaskWizard 的人工关键词保护、建议请求关联、最终配置指纹与启动前重新读取前提仍在；只有合法且匹配当前任务的启动响应才进入成功路径。无效响应不清理未知结果，缺真实画像 / 账号 / 设备时不能启动。这里核对的是调用方行为，独立 ledger 实现由其他成员审核。
- 监控页仅显示服务返回的状态、计数、事件与日程。没有返回值时使用待读取或错误状态，不合成运行历史、零新增或下次运行时间；任务操作失败保留实际状态。
- Electron 保留 sandbox、context isolation、关闭 Node integration、固定 IPC 操作白名单、可信主窗口发送方检查、静态资源白名单和 CSP；网络请求由独立内存会话处理，拒绝重定向，注销请求有序执行并清会话。打包客户端只接受配置的 HTTPS 服务地址。
