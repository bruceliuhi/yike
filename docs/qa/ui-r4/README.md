## 实际浏览器交互

浏览器为 macOS 内置 Chromium，隔离入口 `http://127.0.0.1:18794/?suite=r4&scenario=P02&state=populated`。TEST 适配器只在测试入口提供内存夹具；生产构建排除它，不产生客户写入、采集、发送或计费。

1. P06 取得 TEST 估算后修改搜贝上限，旧估算/规则立即清除并回到待估算；人可编辑词项与上限。
2. P02 三类简报页签与证据展开；部分覆盖不会写成全平台已检查。
3. P09 查看四个方向；上限调整预览显示原上限 30、新上限 50、增加 20；勾选确认后返回未知，再核对原操作得到已调整且任务尚未恢复。恢复原视口后，用鼠标展开 8 个完整关键词并切换任务配置页签。
4. P10 分类过滤与证据选择，进入完整详情；观察类不提供直接联系承诺。
5. P11 查看项目变化及多找类似，选择公开网站与 50 搜贝上限，创建新草稿；新任务页面保留 3 个建议词、2 个排除词、出处和上限，显示待估算、尚未启动。原任务未被恢复或覆盖。960×600 下抽屉为 440×540，顶部 y=60，取消和创建按钮底边 y=584，内容单独滚动。
6. P12 生成前保留旧文本，预览对比与原文后核对替换；[客户态截图](screens/P12.png) 是替换后的“本机修改未同步”，能看到三条采用检查摘要，发送禁用。随后执行保存并在下一次 DOM 读取确认“已保存内容”。截图不冒充保存后的画面。只读样例为单问题 31 字，可复制，不能保存或发送。

最终在 `cbc6170` 重测六页 × 960×600、1280×720、1366×768、1440×1024、1920×1080、2560×1440，共 36 项，无文档横向溢出；实际标题见 JSON。允许长表单自然纵向滚动，不宣称所有操作同时在首屏。恢复两个临时页的设备仿真及浏览器视口后，原生鼠标点击正常；此验收页最终 error 日志为空。

错误、取消、超时、跨空间迟到响应、重复确认、过期版本、失败与未知对账的详细分支由组件/领域测试验证，不把它们全部表述为逐图视觉验收。
