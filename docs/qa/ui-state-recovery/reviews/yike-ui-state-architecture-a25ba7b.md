## 身份、原请求与状态边界

资料页面按 authenticated、用户、客户空间 ID/版本、API 和画像边界隔离。旧空间的抽屉/影响确认失效；迟到回执先检查身份，不能清除其他空间的锁或更新新空间页面。v2 本机记录含 owner 和精确原请求，终态删除前检查完整 key 与 pending；写入/删除后均核对存储结果。

旧 v1 记录不被自动认领到当前空间，保留原文并提供可复制请求 ID；同一空间旧版本锁仍可见且阻止新请求，不借当前空间授权查询。合法带点号的用户/画像 ID 所致初筛碰撞已修复：先验证记录自身完整 key，再跳过合法的其他归属；伪造当前 key 仍拒绝。旧锁的真实归属与结果仍需要原空间或外部证据，UI 没有绕锁按钮。

TaskWizard 仅将同一状态变量同时用于可见文字和显式 aria-label；原有加载、失败、连接/待核验逻辑与启动门禁没有被扩张。勾选平台仅修改配置，登记连接不由本增量转成执行能力。新增回归包含旧空间迟到响应不覆盖新空间错误态。
