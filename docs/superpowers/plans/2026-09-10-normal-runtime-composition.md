## Global Constraints

- All composed stores use the same application `PilotDatabase`; Web never calls the admin database factory, migrations or grants. A nonempty inherited `YIKE_PILOT_ADMIN_DATABASE_URL` is rejected before constructing services, with a fixed value-free error. This guard does not prove the application URL's actual role/ACL is safe; restricted-role and migration/grant validation remain deployment requirements.
- `ResearchStrategyStore.resolve` supplies both execution and review write authorization; `ResearchStrategyStore.read_snapshot` supplies review listing from the same store instance. Do not replace the snapshot reader with the write resolver.
- `ExecutionRuntime.capability_check` remains `None`: no actual installed/accepted source policy currently exists. No environment boolean, platform allowlist or test callback may enable production START. Existing capability flags stay unchanged; source execution and sending are not authorized by constructing services.
- Assessment configuration is server-only, atomic and fail-closed: all three values absent/blank means no model; any partially supplied or invalid configuration aborts with `RuntimeError("invalid_assessment_configuration")` without exposing supplied values or an underlying exception chain. All three present construct the existing `OpenAICompatibleCandidateAssessmentModel` with its default bounded timeout and versioned Skill.
- The exact configuration names are `YIKE_PILOT_ASSESSMENT_BASE_URL`, `YIKE_PILOT_ASSESSMENT_API_KEY`, and `YIKE_PILOT_ASSESSMENT_MODEL`. Do not introduce a timeout/quota tuning interface or arbitrary plugin import path. Only absence classification may strip whitespace; pass present values unchanged to the adapter's existing validation, rather than silently normalizing credentials/model identifiers.
- Construction, health/readiness, capability reads, strategy/candidate GETs and original-request receipt recovery must not call the model or a platform. Only the existing authenticated ASSESS path can invoke the configured model, with its existing quota/deadline/replay/tenant fences. Missing model remains ASSESS=501. No automatic sends.
- Keep admin CLI behavior, proxy allowlist validation, access-log suppression and existing router contracts. No change to phone/SMS configuration, search-suggestion service, default capabilities, shared SQL, source/model workers or desktop in this increment.
- Tests use clearly synthetic controlled inputs. Real restricted PostgreSQL and a local owned HTTP provider validate integration, not actual public collection, commercial model quality, production readiness, normal SMS login or customer response.
