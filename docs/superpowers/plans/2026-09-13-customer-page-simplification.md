# 客户页面信息收敛：设计与实施记录

## 用户要求与设计

2026-09-13 用户指出行业策略小字、补证顺序、停止条件及执行保护上限不应给普通用户增加负担，随后要求其它页面一起排查处理。依据 AGENTS.md 的局部 UI 自主细化授权，本批不重新生成设计图或重复索取设计确认。

采用渐进展示：主页面只保留任务目标、必要输入、结果与下一步；专业参数和规则版本收进默认关闭的“高级设置”或“查看详情”。纯执行教学（补证顺序等）移出客户页面。既有八入口、布局风格、字段值、确认摘要和接口不变。对比全删参数会损失修复入口、重建简易模式会增加维护成本，沿用现有组件折叠最适合本批。

费用/用量确认、当前账号状态、原文与时间、证据不足、失败/结果未知、取消及发送对象/内容确认不得隐藏或弱化。高级字段如有错误，主层显示可行动提示，不能出现不可见阻断。折叠不得清空已编辑配置或使旧确认有效化。
