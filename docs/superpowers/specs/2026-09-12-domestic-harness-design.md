# 国产模型 Codex Worker

依据：已批准V02自主技术细化与用户明确的Codex开源Harness＋国产模型路线；承接`2026-09-12-open-web-research-design.md`，不改变完整产品目标。

选择薄协议适配＋原Codex执行器。直接接当前豆包已实测不能完成工具调用；降级官方CLI对照未取得启动证据，故不采用。自造Agent循环增加维护面，且违背用户偏好。本轮实现已在临时诊断中跑通的协议接法，不沿用含本机密钥路径的诊断脚本。

## 输出与范围

服务端内部函数接收**公开研究描述**、显式运行时/模型配置、宿主上限，启动隔离Codex；返回实际MCP读取证据、失败、模型总结、实际用量和终态。模型总结与原文分开；没有完成工具读取时不得返回成功研究。客户不安装或登录Codex。本批不公开HTTP客户API，不写客户库/审批/账本，不部署。

这是一条可执行的公开**读取研究**链，不冒充自主搜索：模型仅有`yike_public.read_public_page`，宿主提供任务描述与其中的公开来源。实际搜索工具、已有任务许可/预算事务、用户进度接线是同一Goal的下一部分。已有专用平台连接器不受影响。

## 协议适配

`pilot/responses_bridge.py`：每任务临时回环端口，随机Bearer令牌，只收`POST /v1/responses`，只转发到固定Ark HTTPS endpoint。真实供应商key只保留在桥进程内存，Codex只收到临时回环令牌；不读取环境或个人配置。仅允许宿主明确列出的namespace/function，过滤无关工具，拒绝未知返回调用/历史调用，不允许模型决定目标URL/认证/模型/上限。

namespace工具映射到稳定不碰撞的扁平function别名；在返回的`function_call`事件（含response.output）恢复name/namespace，在后续input历史转回别名。只按Responses结构转换，不遍历/改写用户正文或工具参数中的同名业务字段。删掉Ark已确认不支持的`reasoning.summary`；保留其他语义。未支持的协议形态固定失败，不静默降级成文字成功。

宿主限制请求次数1–20、整个任务最多1800秒、请求/单响应最多2MiB，单HTTP I/O等待不超过剩余时长或20秒。单任务转发串行，计数在I/O前，绝不自动重试；关闭监听并终止所有在途等待，不留下凭据或端口。状态记录只含序号、固定码、用量和耗时，不保存headers、原始异常、源参数或响应正文。普通Web服务不会启动桥。

## Worker

`pilot/codex_research_worker.py`：显式绝对路径的Codex和Python、显式模型/key、公开描述≤4000字符。支持当前服务端POSIX执行环境（Linux/macOS），不在Windows客户电脑启动云Worker。新建临时private home/workspace；不继承个人CODEX_HOME、配置、skills、插件、账号、shell环境；进程read-only，禁止shell/apps/plugins/hooks/browser/多Agent等无关能力，MCP使用空环境。配置参数不是操作系统容器隔离，部署仍必须放租户隔离执行容器。

真正父级墙钟、取消及输出2MiB上限终止拥有的进程组并回收；stdout JSONL只认结构化终态和实际完成的MCP事件，重复事件按ID不复计，冲突事件失败。成功工具结果必须匹配参数URL、原文/hash/观察范围以及UNREVIEWED状态。模型自报原文、非MCP事件、未知工具或异常终态不算读取事实。部分已读证据在失败/取消时保留并明确终态，不伪装完成；没有工具读取为`no_verified_reads`。

模型Token用量可为未知；计费由后续资源账本统一处理，本函数不定义售价/搜贝。完整V02/真实搜索/客户闭环/生产上线均不以此批完成。

## 验证

先本地合成传输的协议往返、坏输入/别名/历史/SSE/超时/计数/不回显；再实际可控子进程检查隔离、取消、上限和事件取证。网络替身不替代工具/进程逻辑。只跑改变的测试文件和必要一次真实公开页模型往返，独立审核整批及修复delta，不重跑旧全套或构包。Qwen凭据待定位，不因未测将其判为不兼容。
