# 动态公开网络研究执行层

依据：用户要求不逐站实现全网搜索，以 Codex/Skill 自主探索潜在数据源；侧边任务转达用户确认 UI 需要随之调整。既有 V02 自主技术细化授权继续有效。本文不增加外联、账号访问、费用或部署授权。

**最新用户确认：** 在澄清客户无需Codex后，用户明确“成熟Harness尽量就要codex那套开源的，接入国产模型本地电脑已经有key你可以直接用”，继而要求“按这个开发，完成交付上线”。因此恢复 Codex 开源 Harness 的优先实施路线，以国产商业模型API接入验证为下一步，不自行替换成自造Agent框架。客户仅登录意客；云端运行时、模型供应商、联网工具分别配置验证，不继承开发者个人Codex登录/额度/工具。允许使用本机已有国产模型密钥作有界兼容性验证，密钥不进入仓库、日志、对话或客户端。兼容模型接口不等于兼容Codex内置联网；搜索/网页读取通过独立工具接入。任务/预算/租户/复核继续由意客服务端持有。完整V02 Goal保持不变，不以本批或工具调用成功替代交付上线。

## 选择与边界

采用 **Codex Harness + 通用公开读取 + 原平台深读连接器**。固定目录适合稳定监测，不再是发现范围。纯搜索摘要不足以证明需求；自建另一套模型工具循环不是本批替代方案。

用户进一步确认：小红书、抖音等已有登录、评论展开、稳定监测场景继续复用专用连接器或授权浏览器。通用能力扩大来源范围，专用能力增加读取深度并节省重复执行成本；同一已授权来源有合适的专用读取/有效缓存时优先复用，不为体现Agent而强制浏览器逐页重做。节省比例由实际用量验证，失败不静默换账号或突破授权。

本批交付可调用的内部研究执行层：已确认的公开检索描述 -> 实际 Codex 搜索事件 -> 新 URL -> 独立 HTTPS 原文读取 -> 未判断的证据记录。域名不预先枚举。既有三索引运行模式保持不变，不把新原文直接伪造成 APPROVED 研究包。

完整产品还必须把此执行层接到现有签名任务/资源许可/候选事务、客户进度及监控；本批基础不能作为客户已具备全网研究或生产已启用的证据。研究方法和工具接口分开版本化。

## 本批接口

1. `pilot/open_web_reader.py`：`read_public_page(url: str, *, deadline: datetime) -> dict`。返回 `url,title,text,observed_at,content_sha256,read_scope`；read_scope 固定 `PUBLIC_PAGE_TEXT`，不声称评论完整、发布日期或作者已核实。失败抛 `PublicReadError(code)`，只允许固定安全码。
2. `pilot/codex_discovery.py`：实际受控 `codex exec --json` 调用；输入为调用方显式提供的公开研究描述、排除项和限制，不读取业务私密资料/桌面登录态。输出仅为待读取 URL 和实际工具事件，无模型自报原文作为权威证据。
3. `pilot/open_web_research.py`：搜索 -> URL 去重 -> 按剩余时间读取 -> 候选形状校验 -> 结果。读取失败与无搜索结果分开；搜索/读取记录不是已确认商机。取消/截止后不开始新 I/O；外层持久化与计量接线仍是后续同一目标工作。

## 网络与进程约束

### 通用工具协议

`pilot/research_tools.py` 通过官方 MCP stdio 协议包装同一读器，供云端Codex调用，不另造Agent框架。采用可选依赖 `research` 的 `mcp==1.28.0` 维护线，避免2.2.0所需Pydantic>=2.12/httpx2强升现有应用；普通Web服务不加载此依赖模块。只暴露 `read_public_page(url)`；无HTTP监听、无账号登录/发送/数据库工具。

受信宿主以必填参数限定该进程总读取次数（1–100）和研究存活时间（1–1800秒）；模型不能修改。调用串行，同URL成功或失败均进程内重放，不自动重试；超过截止不新读。输出直接读取的原文、观察时间/hash和UNREVIEWED状态，不能自报发布日期/身份/评分/审批。进程内限制不冒充持久预算账本，后续接入现有资源许可和任务身份；本批工具上线不等于自主搜索完成。

- 通用读器仅匿名 HTTPS/default443；不携带 Cookie、代理或授权头，不跟随跳转，不自动重试。公开 URL 语法复用 candidate_contract，再解析所有 DNS 地址并拒绝任一非公开地址；连接固定已验证地址，TLS SNI/证书验证仍使用原域名，防止校验后重解析。
- DNS、连接、TLS、正文整个读取由父进程截止并杀死/回收子进程；最长20秒、最多1MiB响应、最多60,000字符可见文本。HTML去除脚本/样式等非正文，纯文本可用，其他格式明确不可读，不声称涵盖PDF/动态评论。
- Codex 凭据只能由受信宿主显式传入，不能继承用户 CODEX_HOME/插件/MCP/平台 profile。只读执行，禁用 shell、浏览器账号、apps、插件、hooks、多Agent等非必需能力；这些参数不等于 OS 隔离，真实调用仅允许部署方提供独立沙箱工作区。执行路径必须是显式绝对路径。
- 一次调用有硬墙钟截止和有界输出，最多指定搜索事件数，未知/超时不自动重试，不把模型输出token当费用/搜贝结算。无凭据或运行能力不宣称无需求。
- 网页是数据，不能改变任务/预算/调用权限；模型提出的URL由读器再次校验。模型的解释、工具事件、实际读取正文分别记录。

## UI 对应设计（本批未改页面）

复用 R3/R4 页面：P06 以目标式文字/语音/资料为入口，平台/关键词成为高级控制；P19 确认业务目标、地域、排除项、公开范围和预算；P09 展示真实查询、来源读取/失败及停止原因。未知统计不填0。机会卡复用原文、时间、匹配与缺失证据。没有通用执行能力时不可把现有固定索引标为全网研究。公开研究不要求所有平台先登录；新增平台账号授权仍独立确认。

## 验收

- 两个未在目录中的HTTPS站点可通过相同读器处理；私网DNS、重绑定、重定向、超时、超大响应和脚本内容不能升级成正文证据。
- 受控 Codex 进程输出经过真实解析：只认实际完成事件，拒绝无搜索的答案、异常终止、无效结构、输出溢出；凭据不在 argv、异常或结果中。
- 完整控制器在合成搜索/网络I/O下覆盖去重、多站、部分失败、取消和未判断候选，明确这不是实际公网商机验证。
- 后续真实对照：同画像/时间/费用，比较净新增独立买方、值得联系机会及单位有效机会成本。单纯来源数、读到网页数或Skill文本检查不能证明获客价值。
