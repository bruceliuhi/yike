# 浏览器退出后目录快照变化

范围：修复已停止的 Chromium 档案在枚举后、打开前文件消失导致连接核验误拒绝；不改变 ACL 或登录授权。

证据：固定 2a85dbc runtime 加当前 login worker 的匿名隔离试验，首页 200 后进入 USER_LOGIN_WAIT，Job 超时停止后 CreateFileW 打开根下 lockfile 返回 WinError 2；稍后同档案可核验。确切删除者/底层缓存时序尚未确认，不归因为权限错误。

方案比较：忽略 lockfile 会漏检同名恶意节点；对所有异常重试会掩盖安全失败。选择仅对原生打开返回 FILE_NOT_FOUND 的已枚举后代中止本次遍历，并重新完整遍历，最多三次、无睡眠。只有一次完整成功的遍历才能通过；根与祖先打开失败不可恢复，runtime/output 严格策略不重扫。

保持原所有者、DACL、重解析点、硬链接、句柄固定及脱敏错误。若重扫仍变化则拒绝；不删除、修复或改写用户档案。契约仍是停止自有写入者后的时点检查，不承诺阻止同用户并发写入。

按 AUTHORITY 已授权范围自行细化；集中一次独立审核，不为小修复另造多轮构包。
