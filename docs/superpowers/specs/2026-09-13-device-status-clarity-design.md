# 设备身份与商业绑定状态分离

实机0d9500b：账号已登录，Settings商业account读取未接通时，fallback仍写“尚未完成绑定核验”；真实设备身份仅弹窗显示。两者不同：controller重启为NOT_PREPARED，prepare需本人确认；商业绑定未知不能证明设备身份未核验。

本批仅显示修复：Settings已登录且有deviceIdentity时，以现有getStatus只读窄IPC取得严格解析状态，复用面板标签；打开/关闭身份弹窗后重新读取，账号/服务切换使旧结果立即不可见。缺失/坏响应/超时用固定失败文本。商业绑定无数据写未知，不断言未绑定；补充身份核验不需要授权码的指引。

不自动prepare/register/PROVE，不保存READY或跨重启复用旧证明。自动续验涉及现行明确确认边界，本批不实施。替代方案为完全自动续验（改变认证行为）或仅改一个fallback（仍看不到真实身份），均不采用。原页面布局与管理功能保持，测试和审核集中一次，暂不为此重复构包已装0d9500b。
