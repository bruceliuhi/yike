# 平台登录只读状态同步

## 范围与依据

2a85dbc Windows 实机小红书两次 OPENED 后 FAILED/PLATFORM_RESPONSE_CHANGED，页面仍等待120秒。主进程保存的失败布尔值只在人工 CHECK 时读取；CHECK 同时负责 REGISTER/VERIFY，不能自动调用。依据 AUTHORITY 自主细化授权，修复既有登录流程，不改布局、认证边界或平台判定。

## 选择

采用现有严格IPC上新增 STATUS：比新增事件订阅更少生命周期接点；不采用自动 CHECK，因为会隐式写入连接授权。轮询每秒一次、串行、单次最多5秒，仅在打开后的等待/待检查状态持续，120秒总等待沿用原边界。

主进程按 platform/flowId、当前客户会话及设备凭据校验，只读内存，不读写连接登记、不访问平台、不停止/启动进程。返回 WAITING_LOGIN、LOGIN_READY 或固定白名单 FAILED；登录完成仍须本人点击检查连接。错误只传固定代码，未知消息降为 CONNECTION_FAILED；保持物理停止失败阻止新OPEN的原机制。登录观察过期返回 LOGIN_EXPIRED，不披露账号/路径。

服务层绑定当前flow与原bridge，拒绝错flow、晚结果和非状态响应，禁止无flow时降为登记查询。页面串行读取；出错立即退出等待，显示可操作原因，禁用无效的人工检查，保留重新打开及取消。LOGIN_READY仅显示待人工检查，不宣称已连接。取消、CHECK、换平台/账号/空间、重开及卸载均取消本轮观察，迟到结果不能覆盖新状态。

## 验证与未解决范围

控制器证明STATUS零登记/写入/停止副作用、会话/设备隔离、过期及安全错误；服务测试证明命令仅STATUS与旧flow拒绝；真实React弹窗测试失败及时显示、成功不自动CHECK、串行超时及生命周期迟到保护。保留现有CHECK/取消/停止门禁测试。小红书响应解析根因、设备重启恢复、真实平台授权仍未修；本批通过不代表上线。
