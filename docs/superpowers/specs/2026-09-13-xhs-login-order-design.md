# 小红书登录初始化顺序

2a85dbc实机两次快速PLATFORM_RESPONSE_CHANGED。同包runtime、全新匿名档案独立探针证实：首页HTTP200/官方域→pong→client.request第81行拒绝响应信封，尚未到result.success解析或用户登录等待；另次同样匿名条件pong false→USER_LOGIN_WAIT正常。错误信封数字码未取得，不猜测它是认证、限流或挑战。

当前UI已明确未登录时仍先请求selfinfo，把匿名接口异常作为登录入口前提。方案选择：按官方页面“我”的唯一可见导航先区分是否需本人登录；无导航/不可见则仅调用既有用户等待器（不点登录/不读密码/不解挑战）。登录等待后重新检查官方域，创建同一上下文client并严格pong；任何失败仍失败关闭；最终仍核对唯一可见self链接及账号格式。已登录导航保持直接严格pong，不将未知错误变成未登录。歧义导航count>1立即拒绝，不任意选账号。

不采用吞掉PLATFORM_RESPONSE_CHANGED或放宽success判断，不改vendor补丁/锁/平台权限。旧client.pong路径的采集检查本批不改；用户认证、真实采集与发送仍须验。

测试：匿名导航下pong不准先于用户等待；等待后失败/挑战/错误域不认证；已登录正常路径保留；歧义导航、无真实self账号或清理失败均拒绝。实际匿名同runtime只能证明进入等待且物理停止，不证明登录成功。
