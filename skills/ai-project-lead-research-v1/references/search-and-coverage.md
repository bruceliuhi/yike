# 搜索与覆盖：从业务表达扩展，不维护封闭关键词白名单

## 1. 先展开可交付物

从用户服务目录提取可交付能力；下表是可扩展的种子而非范围上限。新行业只要业务动作与能力有关就可研究；尚未证明的交付经验不要作为筛选必须项。行业资质、硬件现场配合等记录给销售判断，不提前做合作交付架构。

| 能力族 | 技术/产品说法 | 买方可能不提 AI 的说法 |
|---|---|---|
| 知识与文档 | 知识库、RAG、文档问答、知识图谱、企业搜索、OCR、合同/票据抽取 | 资料查不到、答案没出处、版本乱、表格读不准、扫描件录入、合同条款比对 |
| 客服与服务 | 智能客服、工单、语音机器人、多语言客服、售后助手 | 晚上没人回、订单查不到、机器人答非所问、退款转人工、跨境时差、话术不统一 |
| 教育与训练 | AI学伴、口语陪练、课程助手、智能批改、题库、备课、模拟面试、销售陪练 | 课程接小程序、课后反馈费人、陪练跟不上、作业点评、练习个性化、员工培训考核 |
| 业务 Agent | 智能体、工作流、工具调用、RPA、业务助手、自动化、Dify/Coze/n8n 二开 | 每天复制粘贴、跨系统录单、做日报、查库存报价、跟进漏单、审批资料整理 |
| 模型与部署 | 微调、训练、蒸馏、推理、私有化/本地化、离线、模型评测、降成本 | 数据不出公司、现有模型不好用、响应慢、GPU资源不足、推理费太高、供应商换型 |
| 数据工程 | 标注、清洗、脱敏、语料、质检、合成数据、评测集、数据集 | 有一批录音/图片要处理、标注团队、样本不一致、抽检不过、批量分类、数据对接 |
| 视觉与工业 | 机器视觉、质检、缺陷检测、分割、计数、识别、多模态 | 人工漏检、识别污渍裂纹、图纸识别、摄像头统计、检测误报、票据图像整理 |
| 音视频与创作 | 图片/视频生成、数字人、配音、转写、批量剪辑、虚拟试穿、3D | 商品图批量做、口播多语言、直播素材、录音整理、素材检索、视频制作产能 |
| 行业工具与系统 | AI SaaS、插件、小程序/App、智能硬件软件、行业助手 | 现有系统想加功能、接订单/教务/ERP/CRM、能不能按我们流程做、原外包交不了要接手 |

行业切片包括但不限于电商、外贸、制造、培训、财税、咨询、法律服务、物流、文旅、地产、零售、医疗健康企业。不要把有监管门槛的行业一律排除，也不要把资质未核实当已具备。仍执行本用户对政府/事业单位等的排除。

AI 辅导有双义：找老师教用 AI ≠ 找团队做辅导产品。AI 编程写出来的普通网站 ≠ 买方要 AI 系统。按购买对象和任务授权判断，不靠字面。

## 2. 四条发现路径

1. **直接寻源**：找团队、求推荐公司、有偿开发、项目合作、整包、按项目结算、二开、接入、谁能做、可报价、近期上线。
2. **失败/替换**：搭了用不了、一直答错、接不进系统、原供应商停了、需要接手、准备换方案。痛点只是种子，要补是否愿找外部帮助。
3. **需求评论**：相关演示、实施复盘、行业问题帖下，需求作者说“我们公司也有这个问题/能接我们的系统吗/找人做”。展开上下文与作者回复；不要把博主当买方。
4. **带项目的合作方**：软件商、顾问、机构明确有在手客户、交付物及寻团队动作。渠道线索单独统计；纯供应商入库、互换资源不算项目机会。

搜索表达可由“业务对象 + 问题/交付物 + 动作”组合，也可只取两个词避免过窄。例：课程 小程序 有偿对接；客服 订单 接口；工厂 质检 找团队；行业录音 标签 外包；本地知识库 接手；业务系统 智能化 改造；合同抽取 批量；外贸 询盘 自动整理。借原文新词继续扩展，不机械穷举行业×工具×平台的组合。

## 3. 平台选择与执行

- 小红书、抖音、B站：主帖与评论并行，实际换独立作者/业务圈，兼顾低热度新需求与旧优质主题下的新评论。
- 知乎、微博、即刻、贴吧：找本人业务问题/求方案及后续更新；转载新闻和泛讨论只作种子。
- V2EX、电鸭、LINUX DO、公开行业/工具社区：近期版块/标签/公开任务页经常比搜索引擎收录更及时；招聘标签按正文合作方式复核。
- 当本任务允许正式采购时，加入买方企业官网的采购/招标公告栏目；按买方行业、交付物和采购动作搜索，不把技术社区当默认唯一来源。企业采购、政府/事业单位采购和普通直接需求分开，仍遵守用户的主体、竞标形式及资质排除。聚合页只帮助定位原始公告，不是已核验采购证据；不替客户注册、付费获取文件或提交投标。
- 海外只找中文或明确能中文沟通的帖子/社区；不假定外国人能中文。用户排除的平台保持排除。

以上是备选来源，不是假定都可访问。使用可用授权工具；只有站外摘要时注明未深入，不能声称搜过全部评论。公共工具受限就记录原因；对登录/风控受阻的平台暂停，不绕过。普通空结果可调整业务表达或改查公开近期版块。

选一个有界研究批次，默认约 30–60 分钟，明确本次优先平台、能力族、主帖/评论与补证时间。约半数精力投向已产出有效证据的来源，剩余探索新场景/作者/平台；比例可按实际改变。用户要求更多时连续批次推进并保存游标，不因默认展示10条就停止采样。

## 4. 记录真正的覆盖

每条已执行查询记录：平台、时间、确切查询/入口、业务假设、排序/时间筛选（若实设）、浏览深度、打开原文数、原帖作者ID集合、需求作者ID集合、项目ID、退出原因。未知不能写0。计划另列，不计完成。

汇总时分母分开：查询数、结果卡数、打开主帖数、展开评论串数、独立内容作者数、独立需求作者数、去重项目数、补证通过数。多个视频来自一个博主就是一个内容作者，不能相加昵称得出独立买方数。

同一来源连续出现广告/重复/旧帖，换需求表达和独立来源，不持续翻同一 KOL。访问障碍多则先修访问；零候选则抽看被排除样本，查是否标题、预算或缺微信导致误杀。没有完成足够独立覆盖，只能说本轮未发现，不能断言全网没有。
