# 意客 AI 官方产品官网

这是 `yike-ai2026` 内独立维护的对外产品网站，源码与桌面客户端、客户情报 CRM 分开，便于长期发布和版本化迭代。

## 本地预览

```bash
cd website
npm run build
npm run preview
```

页面：

- `/` 产品首页
- `/products/workbench/` 商机工作台
- `/products/crm/` 客户情报 CRM
- `/features/` 能力全景
- `/download/` 下载与试用
- `/roadmap/` 产品路线
- `/contact/` 预约演示

## 对外口径

官网把“客户端已提供”“按连接状态提供”“企业方案”“持续建设”分开表达。未完成或未完成真实验收的能力可以作为产品方向和企业方案介绍，但不能冒充当前版本已部署或已验证。

CRM 当前按网页产品和部署申请介绍，没有伪造桌面安装包下载；客户端包上线后只需在 `src/data.js` 或下载页接入经过核验的版本 URL。

## 发布

执行 `npm run build`，将 `dist/` 发布到独立静态站点。建议使用版本化目录和 `current` 符号链接，发布前检查所有路由、图片、移动端首屏和下载入口。
