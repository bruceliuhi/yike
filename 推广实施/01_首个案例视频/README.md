# 意客 AI 首个案例视频执行包

## 目标

用一条真实、可复核的产品操作视频，让软件定制 / IT 服务公司的销售在 45 秒内理解：

> 意客 AI 把公开需求，变成销售今天能跟进的机会

第一条视频只验证三个问题：

1. 目标客户能否看懂产品解决什么问题；
2. 客户是否愿意留下业务方向申请试用；
3. 客户是否认可机会卡中的原文证据和下一步建议。

## 视频原则

- 70% 是真实软件操作，20% 是客户问题和上下文，10% 是行动入口。
- 优先录制完整桌面操作，再剪成 9:16、16:9 两个版本。
- 录制真实页面、真实流程；如果使用演示数据，画面必须标注“演示数据”。
- 不展示虚构客户、虚构成交额、虚构回复和未经验证的平台能力。
- 原文来源、账号名、手机号和私信内容必须脱敏。

## 主视频链路

公开内容 → 需求信号 → 机会卡 → 证据与匹配理由 → 联系短句 → 试用入口

## 发布版本

| 版本 | 时长 | 平台 | 目标 |
| --- | ---: | --- | --- |
| 竖屏短版 | 35–45 秒 | 抖音、视频号、小红书 | 让客户停留并点击 |
| 横屏演示版 | 90–120 秒 | B 站、公众号 | 让客户理解完整流程 |
| 销售演示版 | 5–8 分钟 | 预约演示、私域 | 完成试用转化 |

**看一条真实机会**

次级入口为“申请 7 天试用”。不要在同一条视频中同时出现下载、加微信、领取资料、预约会议等多个动作。
