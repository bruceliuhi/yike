# 首条视频验收指标

## 发布前

- [ ] 画面使用真实产品流程
- [ ] 演示数据、账号名和链接已脱敏
- [ ] 所有被展示的平台状态与实际能力一致
- [ ] 页面上的试用入口可打开
- [ ] 每个平台有独立 UTM 参数

## 发布后 7 天

记录以下事件，不以播放量作为唯一结果：

- 播放完成率
- 点击“看一条真实机会”的人数
- 提交行业和业务方向的人数
- 获得试用码的人数
- 首次生成机会卡的人数
- 销售认可的机会数
- 真实触达数
- 有实质回复的机会数
- 进入付费试点的客户数

## 首轮判断

- 有播放、无点击：开头没有讲清楚客户问题。
- 有点击、无试用：案例和产品价值之间缺少证据。
- 有试用、无认可：机会卡质量或匹配理由不够可信。
- 有认可、无触达：触达短句、流程或客户权限存在阻力。
- 有触达、无回复：需要检查目标行业、需求类型和跟进时机，不要马上加更多功能。
